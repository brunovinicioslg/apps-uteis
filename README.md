# Apps Úteis

Apps Android gratuitos, sem anúncios e de código aberto.

| App | O que faz | Pasta |
|---|---|---|
| **Alumia** | Liga a lanterna ao chacoalhar o celular, mesmo com a tela bloqueada | [lanterna/](lanterna/) |
| **Mede Aí** | Trena pela câmera: distância, altura e área | [trena/](trena/) |
| **Ladeira** | GPS offline que avisa sobre subidas e descidas, radares e buracos | [gps-relevo/](gps-relevo/) |
| **Sigilo** | Mensagens SMS criptografadas de ponta a ponta, sem servidor | [sms-seguro/](sms-seguro/) |
| **Sossego** | Bloqueia chamadas em silêncio (lista negra, só lista branca ou tudo) e liga pelo teclado, contatos e recentes | [bloqueador/](bloqueador/) |
| **Tijolão** | Emulador de jogos Java (J2ME) com biblioteca e avaliações; uso pessoal, sem jogos no repositório | [tijolao/](tijolao/) |

Plano de desenvolvimento: [PLANO.md](PLANO.md)
Publicação na Google Play: [PUBLICAR.md](PUBLICAR.md). Cada app tem sua política de privacidade na pasta (`PRIVACIDADE.md`).
